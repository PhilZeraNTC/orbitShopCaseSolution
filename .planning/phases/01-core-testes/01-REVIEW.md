### WR-01: Unfilled left-join NaNs in `reconcile_orders_vs_items` when an order has zero items

**File:** `src/audit.py:129-131`
**Issue:** `pedidos.merge(agg_itens, left_on="id", right_on="pedido_id", how="left")` leaves `qtd_itens`, `unidades`, `soma_bruta_itens`, `soma_liquida_itens`, `custo_pedido`, `lucro_pedido`, and `tem_desc_nulo` as `NaN` if any order in `pedidos` has no matching rows in `itens_full`, causing `diff_liquida`, `diff_bruta`, and `soma_liquida_itens` comparisons to silently propagate `NaN` instead of treating zero-item orders as `0.0`.
**Fix:**
```python
    rec = pedidos.merge(agg_itens, left_on="id", right_on="pedido_id", how="left").copy()
    rec["qtd_itens"] = rec["qtd_itens"].fillna(0).astype(int)
    rec["unidades"] = rec["unidades"].fillna(0).astype(int)
    for col in ("soma_bruta_itens", "soma_liquida_itens", "custo_pedido", "lucro_pedido"):
        rec[col] = rec[col].fillna(0.0)
    rec["tem_desc_nulo"] = rec["tem_desc_nulo"].fillna(False).astype(bool)
    rec["diff_liquida"] = rec["valor_total"] - rec["soma_liquida_itens"]
    rec["diff_bruta"] = rec["valor_total"] - rec["soma_bruta_itens"]
```

### WR-03: Unfilled `NaN` in supplier ticket/review left-merges in `metrics_q7_suppliers`

**File:** `src/metrics.py:331-338`
**Issue:** `vendas_forn.merge(aval_forn, on="fornecedor", how="left").merge(tkt_forn_agg, on="fornecedor", how="left")` leaves `qtd_avaliacoes`, `tickets_associados`, and `tickets_defeito_troca` as `NaN` if a supplier has zero reviews or zero support tickets, causing `tickets_por_100_itens` to evaluate to `NaN` instead of `0.0`.
**Fix:**
```python
    q7_forn = (
        vendas_forn.merge(aval_forn, on="fornecedor", how="left")
        .merge(tkt_forn_agg, on="fornecedor", how="left")
    )
    for int_col in ("qtd_avaliacoes", "tickets_associados", "tickets_defeito_troca"):
        q7_forn[int_col] = q7_forn[int_col].fillna(0).astype(int)
    q7_forn["tickets_por_100_itens"] = (
        q7_forn["tickets_associados"] / q7_forn["itens_vendidos"] * 100.0
    )
```

### WR-04: `Makefile` target `reproduce` runs `test` before regenerating figures and notebook outputs

**File:** `Makefile:9-15`
**Issue:** `reproduce: test` executes `pytest` before running `python -m src.charts` and `jupyter nbconvert --execute`. On a clean checkout where deliverable artifacts are regenerated by `make reproduce`, running `pytest` first can test stale or not-yet-generated outputs instead of verifying the freshly reproduced artifacts.
**Fix:**
```makefile
reproduce:
	@if [ -f src/charts.py ]; then uv run python -m src.charts; fi
	@if [ -f notebooks/02_analise_executiva.ipynb ]; then \
		uv run jupyter nbconvert --to notebook --execute --inplace notebooks/02_analise_executiva.ipynb && \
		cp notebooks/02_analise_executiva.ipynb notebooks/analise_orbitshop.ipynb; \
	fi
	$(MAKE) test
```
